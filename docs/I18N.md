# Internationalization

## Overview

Custom i18n system — no framework dependency. Three full dictionaries stored in a single file (`src/i18n.ts`), selected at runtime via React context.

## Language Configuration

```typescript
type Lang = 'fr' | 'en' | 'ar';

const LANGUAGES = [
  { code: 'fr', label: 'Français', flag: '🇫🇷', dir: 'ltr' },
  { code: 'en', label: 'English',   flag: '🇬🇧', dir: 'ltr' },
  { code: 'ar', label: 'العربية',    flag: '🇩🇿', dir: 'rtl' },
];
```

## Translation Function

```typescript
t(key: string, lang: Lang, ...args: string[]): string
```

- Looks up `key` in the active language dictionary.
- If the value is a function, calls it with the provided args.
- Falls back to returning the key itself if not found.

## Dictionary Structure

Keys follow a dot-separated namespace convention:

| Namespace | Content |
|---|---|
| `nav.*` | Navigation items |
| `hero.*`, `stat.*`, `section.*`, `feat.*`, `cta.*`, `footer.*` | Landing page |
| `dashboard.*` | Dashboard labels, greetings, KPIs, quick actions |
| `auth.*`, `login.*`, `register.*` | Auth forms |
| `errors.*`, `success.*` | Toast and error messages |
| `validation.*` | Form validation errors |
| `courses.*`, `payments.*`, `invoices.*` | Domain labels |
| `teacher.*`, `parent.*` | Role-specific labels |
| `common.*` | Generic UI (save, cancel, edit, delete, search) |
| `status.*` | Status badge labels |
| `role.*` | Role display names |
| `calendar.*` | Months, days |
| `settings.*`, `profile.*` | Settings/profile |
| `homework.*`, `reviews.*`, `attendance.*` | Domain labels |
| `demo.*`, `alert.*`, `protected.*`, `forgot.*` | Misc |
| `enroll.*` | Enrollment flow |

## Language Context

`src/contexts/LangContext.tsx`:

```typescript
const { lang, dir, setLang } = useLang();
```

- Stores `lang` (default `'fr'`) and `dir` (`'ltr'` | `'rtl'`) in React context.
- Persists to `localStorage`.
- Sets `document.documentElement` `lang` and `dir` attributes.
- `setLang(newLang)` updates context, localStorage, and document attributes.

## Usage in Components

```typescript
import { t } from '@/i18n';
import { useLang } from '@/contexts/LangContext';

function MyComponent() {
  const { lang } = useLang();
  return <h1>{t('dashboard.greeting', lang, firstName)}</h1>;
}
```

## Adding a New Key

1. Add the key to all three dictionaries (`fr`, `en`, `ar`) in `src/i18n.ts`.
2. Use the key via `t('namespace.key', lang, ...args)`.
3. For parameterized messages, use a function value:

```typescript
'welcome_user': (name: string) => `Welcome back, ${name}!`,
```
