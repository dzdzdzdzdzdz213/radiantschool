# Radiant Learning — ERP Centre de Soutien Scolaire

**Live:** [erp-platform-seven.vercel.app](https://erp-platform-seven.vercel.app)

Platforme de gestion pour centre de soutien scolaire — tableau de bord administrateur, gestion des cours, paiements, présences, emploi du temps, messagerie.

## Stack

- **Frontend:** React 19, TypeScript 6, Vite 8, Tailwind CSS 4
- **State:** TanStack React Query 5
- **Backend:** Supabase (PostgreSQL, Auth, Realtime, Storage)
- **Charts:** Recharts
- **Animation:** Framer Motion
- **Deployment:** Vercel (linked — auto-deploys on push to `main`)
